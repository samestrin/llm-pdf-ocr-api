Read a PDF

Your PDF is processed here and not stored: the file is dropped when its job ends, and the text and page images are deleted {{job_ttl}} later.

Your results appear here

Pick a PDF, or press Try a sample, then press Extract. Each page's text appears beside its image, followed by the whole document as Markdown or JSON to copy or download.

Auto
Each page's own text layer when it is usable; otherwise OCR.
Text layer
Only the text stored in the PDF. Fast, but a scanned page fails.
Tesseract
OCR of the page image, with a confidence from 0 to 1.
Vision model
An AI vision model reads the page image. The image is sent to that model.
